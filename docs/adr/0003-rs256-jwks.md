# ADR 0003: RS256 JWKS for inter-service auth

**Date:** 2026-09-14  
**Status:** Accepted

## Context

HS256 shared secret would leak to every service. StatusesGuard called Core’s user DB.

## Decision

Core signs access tokens RS256 (`kid: core-2026-09`) when a private key is present, publishes JWKS, embeds `statuses` in the payload. Trip/Geo verify offline. HS256 remains the fallback.

## Consequences

Need key files (`infra/jwt/generate-dev-keys.js`). Ban takes effect at token expiry unless a revoke stream is consumed.
